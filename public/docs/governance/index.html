    Governance and license

    LicoArc source is available under Apache-2.0; protocol publication and federation governance remain separately controlled lifecycle concerns.

    Apache License 2.0

    The Lico Arc Protocol repository is licensed under the Apache License, Version 2.0. Read the repository license for the complete terms and notices.

    LICENSEApache-2.0 license text

    Contributing to the definition

    Protocol changes must preserve the canonical field authority, closed source graph, deterministic generation, conformance coverage, and lifecycle boundaries. Proposals do not redefine protocol meaning until accepted, implemented, and verified in the owning repository.

    SOURCEContribution guide

    Publication is separate

    The current Protocol Line is a Candidate and explicitly publication ineligible. Publishing repository source or deploying this documentation website does not move the line to Published, certify compatibility, or establish a committee, service, network, or support commitment.

    Federation governance is protocol evidence

    The capability defines threshold-controlled statements and deterministic evaluation. It does not define committee operations, credentials, signing services, accounts, hosted infrastructure, or a final Endpoint trust decision.
