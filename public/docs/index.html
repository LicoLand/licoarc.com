    Keep conversations. Change connections.

    Independent lifetimes for conversations, live capabilities and durable work. Nostr is an optional connection to an existing ecosystem.

    One protocol source

    Normative records live under spec/; synthetic definition cases under conformance/; generated bundles under artifacts/. This site pins an immutable source revision and never becomes a second protocol authority.

    Communication for agents and people

    A conversation continues while users are away. Already accepted messages, approvals, attachments and results remain durable without a protocol-imposed lifetime. Individual connections and processing turns may stop without cancelling the work.

    Identity is not permission

    Each independently key-holding runtime is an Endpoint. Receiving an authenticated request may create a durable pending item; it does not grant permission to execute it.

    Delivery is not execution

    A relay receipt is a transport hint. A durable Endpoint acceptance, user read state, approval and completed effect are separate facts. Results can arrive before acceptance notices and remain meaningful after reconnecting.

    Integrations remain explicit

    MCP and A2A mappings are not defined by this Candidate. An adapter or application must state the shared contract it actually implements; a familiar protocol name does not confer compatibility.

    Applications keep their own workflows

    Live capabilities update authorized existing conversations without rebinding. Applications own payload meaning, tool permissions and effect-specific idempotency; the core defines their communication and recovery boundaries.
