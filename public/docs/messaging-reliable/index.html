    Messages wait. Capabilities evolve. Results persist.

    Conversation continuity, live application updates and reliable facts are independent of connection lifetimes.

    V1 / Generation 1 — Candidate, PARTIAL. This revision changes the security transcript. Formal proof requalification is required; new-session eligibility is false and the Protocol Line is publication ineligible. Standard Nostr messaging remains a separate upstream contract. Definition tests do not establish deployed client support.

    Application-neutral messages

    The six core classes remain event, request, response, error, cancel and streamChunk. Typed application definitions supply meaning. Protected live capability records update only authorized audiences, with separate invoke/provide roles, availability and execution permission; tools can change in an existing conversation without rebinding.

    Resumable attachments without an age limit

    An accepted attachment declaration and its incomplete chunks remain recoverable after the user returns. The old one-day recovery deadline is removed. The existing bounded attachment grammar remains; no unlimited file-size claim is made. Declared digests, chunk validation and explicit storage quotas still apply.

    Durable intent outlives an attempt

    Connection failure, a processing budget or a route change may pause delivery, not terminate the accepted request. Persist before acknowledging custody. Retransmission preserves logical identity; safe reprotection on a new session does not create another execution authorization. Receiving and storing a request does not require prior tool-execution approval.

    Record facts in any network order

    An authenticated completion can arrive before an acceptance notice. The same result over a new authenticated session remains the same fact. Identical repeats are coalesced instead of building unbounded confirmation history. Conflicting authenticated evidence is retained and stops automatic execution decisions. Missing evidence is unknown, not proof of failure.

    Cancellation is a request, not a time machine

    Retain the cancellation intent and the executor’s confirmed outcome separately. A late completion may describe work already performed; recording it must not restart the task. Unknown external effects require inquiry or explicit reconciliation rather than blind retries on another Agent.

    Recover durable responsibility

    Recover inbox, outbox, identity and deduplication state before processing. A delivery copy to another device is not another execution assignment. Accepted records and deduplication guards are not disposable UI caches; delete or compact them only after the declared settlement and recovery conditions are met.
