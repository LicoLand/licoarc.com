    Nostr reach. Independent LicoArc core.

    Connect to the Nostr network without making it the authority for identity, storage or the lifetime of work.

    V1 / Generation 1 — Candidate, PARTIAL. This revision changes the security transcript. Formal proof requalification is required; new-session eligibility is false and the Protocol Line is publication ineligible. Standard Nostr messaging remains a separate upstream contract. Definition tests do not establish deployed client support.

    Two paths, neither a client-brand gate

    Standard private messaging follows NIP-17, NIP-44 v2 and NIP-59 over NIP-01. Enhanced peers additionally implement the open binding and Endpoint core. An enhanced-only service need not implement a chat interface. Neither path requires LicoUp or official federation membership.

    Ordinary Nostr messages stay ordinary

    The standard path keeps kind 14 rumors, kind 13 seals, kind 1059 gift wraps and authenticated kind 10050 recipient inbox lists. NIP-42 is used when the selected relay requires it. Do not put executable commands in chat or infer a sender from a random wrapper key.

    Bind identity once; update capabilities continuously

    The experimental, upstream-unallocated inner kind 44900 and exact licoarc.v1 namespace identify enhanced objects. Identity binding names a stable conversation separately from the transport session. Live capability records are protected updates, not frozen binding fields. Invoke/provide roles, availability and execution permission are distinct. Updates reach authorized existing conversations without rebinding or reconnecting; offline peers catch up using durable records and paged snapshots.

    Preserve protection while changing routes

    An enhanced operation must never silently become ordinary chat, plaintext or a weaker compatibility copy. Switching an authorized carrier with the same recipient and protection is not a downgrade. Pending pairing has no fixed lifetime; temporary processing limits pause work rather than expire it. A later transport attempt may refresh the outer envelope while preserving the same protected intent and task identity.

    Nostr is optional, not the communication authority

    The Endpoint core has five required capabilities. Group collaboration, native HTTPS transport and federation governance have separate targets. Core work remains valid with Nostr disabled. Relay retention and reachability are service properties, not a promise that any public relay stores everything forever. Timestamp-only synchronization is insufficient for arbitrarily late uploads; pending identities and missing data need reconciliation.

    Definition evidence, not runtime qualification

    The framing, association, capability and recovery tests are not production cryptography or a real-client interoperability result. The revised native security model is PARTIAL pending proof requalification, so the enhanced adapter must honor the disabled native session-admission gate. It cannot enable the new security profile merely because its own binding is specified. NIP-44 itself does not supply forward secrecy, post-compromise recovery or post-quantum protection.
