    Separate people, devices and delivery.

    A lasting conversation is not a socket, and a task is not one transmission attempt.

    V1 / Generation 1 — Candidate, PARTIAL. This revision changes the security transcript. Formal proof requalification is required; new-session eligibility is false and the Protocol Line is publication ineligible. Standard Nostr messaging remains a separate upstream contract. Definition tests do not establish deployed client support.

    Endpoint

    An independently key-holding device or isolated runtime controls its keys, plaintext, peer trust, approvals and effects. A user being away does not mean the device cannot receive and persist messages.

    Station

    An untrusted intermediary carries opaque protected records. A custody implementation persists accepted bytes before acknowledging storage and retains them until authorized settlement or transfer of responsibility. Its receipt never proves an Endpoint received or executed a task.

    Network

    An interoperability context is not an identity root or execution authority. Nostr is one optional carrier ecosystem, not a required core dependency.

    Group is an object

    A Group is protected membership state, not a fourth core entity. Device copies, delivery to a person and permission to execute on a named device remain different concerns.

    Four independent lifetimes

    A conversation persists through reconnects. The security session can rotate. Application capabilities change without rebinding. A stable protected work request survives all three without becoming a second operation. Resource budgets bound processing, not the lifetime of accepted work.
