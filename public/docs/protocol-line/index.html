    Semantic identity changes when meaning changes

    V1 and package 0.1.0 remain unchanged. Removing calendar fields from prekey admission changes signed transcript bytes; current Profile, line and binding identities are recomputed from their semantic sources. Keeping the generation does not justify keeping stale content digests.

    Admission follows actual evidence

    The revised sources and corpora are checked, but the old formal model does not prove the new definition. Security requalification remains an explicit blocker; new native sessions remain ineligible until the updated model, proof bindings and current positive cryptographic fixtures are admitted.

    Fixed security context, live application context

    Native cryptographic context remains exact and authenticated. Capabilities are separately authenticated, revisioned application records; adding a tool never requires changing identity or reopening a conversation. An adapter cannot bypass the native admission gate.
