    Semantic identity

    The line identity is a domain-separated digest over its named non-circular semantic projection. It includes Generation 1, ordered mandatory capability semantic identities, active protection profile identities, stable positive claim identifiers, and session rules. Lifecycle and publication metadata are excluded so they do not create circular identity.

    Definition admission

    Admission requires every mandatory capability and active profile to be complete, stable positive claims to carry their required formal bindings, declared positive and negative corpora to close, semantic identities to recompute, the tracked graph to close, and deterministic artifact generation to reproduce the checked bundle.

    Candidate is mutable. COMPLETE reports source-owned definition closure. Session eligible permits sessions under this fixed definition. Publication ineligible means the definition state does not authorize publication.

    Fixed context, no negotiation list

    The initial line authenticates one exact content identity during establishment. It does not exchange a version list or translate between generations. An unknown or mismatched identity rejects before state advance.
